# Examination Hall Ticket Management System

## About the Project

The Examination Hall Ticket Management System is a Java-based application designed to manage student examination hall tickets and seat allocation.

## Features

* Student and Person classes using inheritance.
* Hall ticket generation and validation.
* Ticket ID checksum validation.
* Custom exception handling.
* Generic validation using `Validator<T>`.
* Examination hall seat allocation.
* Avoids placing students writing the same exam next to each other.
* Batch validation using concurrent processing.

## Technologies Used

* Java
* Object-Oriented Programming
* Generics
* Exception Handling
* Multithreading and Concurrency

## Project Structure

* `Main.java` – Contains the classes and main application logic.

## How to Run

1. Download `Main.java`.
2. Open it using a Java editor or IDE.
3. Compile and run the program using Java.
